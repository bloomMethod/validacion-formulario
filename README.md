Formly — Formulaire de création de compte

Formly est un projet Front-End qui consiste à créer une interface moderne de création de compte, avec un formulaire interactif et une validation des données en JavaScript.

L'objectif de ce projet est de pratiquer HTML, CSS et JavaScript, tout en travaillant sur la manipulation du DOM, la gestion des événements et la validation des formulaires.

Aperçu du projet

Formly propose une interface simple et épurée permettant à l'utilisateur de saisir ses informations pour créer un compte.

Fonctionnalités

Formulaire de création de compte.

Validation du nom obligatoire.

Vérification du format de l'adresse e-mail.

Vérification de la longueur minimale du mot de passe (6 caractères).

Confirmation du mot de passe.

Vérification en temps réel après la première validation d'un champ.

Messages d'erreur personnalisés.

Indicateurs visuels pour les champs valides et invalides.

Affichage d'un message de succès lorsque tous les champs sont correctement remplis.

Sauvegarde du nom de l'utilisateur dans localStorage.

Technologies utilisées

HTML5 — Structure de la page.

CSS3 — Mise en page et design responsive.

JavaScript — Validation du formulaire, manipulation du DOM et gestion des événements.

LocalStorage — Sauvegarde du nom de l'utilisateur dans le navigateur.
